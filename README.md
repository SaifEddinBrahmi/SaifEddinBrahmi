## About Me

I'm interested in building intelligent robotic and vision-based systems, from perception algorithms to real-world deployment.

I'm currently working on **collaborative robotics and physical human-robot interaction (pHRI)**, developing perception-control pipelines that combine computer vision, 3D object pose estimation, human motion analysis, and robot control.

My main interests include:

- **Robotics Software Engineering**
- **Computer Vision & Deep Learning**
- **Robot Perception & 3D Pose Estimation**
- **Autonomous & Collaborative Robotics**
- **ROS2, Real-Time Systems & Embedded AI**

## Current Focus

- Developing vision-based perception pipelines for collaborative robotic systems
- Integrating object pose estimation, human motion tracking, and robot control
- Deploying robotics algorithms on real and simulated platforms
- Building open-source projects in robotics, computer vision, and autonomous systems
